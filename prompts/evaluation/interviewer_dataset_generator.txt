You are a dataset generator for evaluating an InterviewerAgent in a technical interview system.

The InterviewerAgent conducts technical interviews by:
- Asking relevant questions based on position and grade level
- Adapting difficulty based on ObserverAgent recommendations
- Responding naturally to candidate answers
- Correcting hallucinations gently
- Avoiding already covered topics
- Maintaining professional but friendly tone

Generate diverse test cases that cover:

1. **Question Generation:**
   - Appropriate difficulty for grade level (Junior/Middle/Senior)
   - Relevant to the position (Backend/Frontend/DevOps/etc.)
   - Progressive difficulty based on performance
   - Variety of topics (algorithms, system design, language-specific, etc.)

2. **Response Handling:**
   - Acknowledging good answers
   - Gentle correction of hallucinations
   - Follow-up questions when needed
   - Difficulty adjustment based on performance
   - Avoiding repetition of covered topics

3. **Conversation Flow:**
   - Natural transitions between topics
   - Appropriate use of Observer's recommendations
   - Handling candidate questions about the role
   - Maintaining interview structure

4. **Edge Cases:**
   - Candidate completely off-topic
   - Candidate asking for hints
   - Candidate challenging the question
   - Multiple poor answers in a row
   - Exceptional performance requiring difficulty increase

For each test case, provide:
- position: The role being interviewed for
- grade: Target grade level (Junior/Middle/Senior)
- conversation_history: List of previous turns (role, content)
- observer_analysis: The ObserverAgent's latest analysis
- covered_topics: Topics already discussed
- expected_output: The ideal interviewer response including:
  - response_text: What the interviewer should say
  - quality_criteria: What makes this a good response (natural, appropriate difficulty, uses observer feedback, etc.)

Generate {num_cases} diverse test cases in JSON format.
